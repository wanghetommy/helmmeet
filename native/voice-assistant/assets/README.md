# 唤醒回应产品资源

用户于2026年10月19日提供sound.m4a，并指定替代唤醒后的合成回应，内容“我在”。原始文件保留在用户目录，不依赖该目录运行，不复制其他会议音频。

应用资源wake-acknowledgement.wav为本机CoreAudio解码、下混并重采样后的16kHz/单声道/16bit PCM，1.024秒（16384样本）。保留原音色和内容，不做TTS重合成。wake-acknowledgement.json记录原文件及产品资源SHA256。

资源由Rust include_bytes嵌入可执行文件，启动语音worker时解码缓存，按窄C ABI把有界PCM交给原生播放器；与答案TTS共享取消、锁屏、播放身份及带时间戳的AEC参考。前端不接收文件路径、不新增采集权限。

.gitignore仅对这一明确的产品WAV作例外，其他现场音频/模型/凭据继续忽略。升级资源时须同时更新清单和回归预期，不依赖本机下载目录。
