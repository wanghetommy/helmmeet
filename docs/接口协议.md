# 接口与数据协议

协议版本：1 · 日期：2026年10月18日

## 1 当前实现与后续协议

当前注册 `get_system_status` 和受限枚举分发命令 `dispatch`。前端调用 `dispatch({operation:{kind,...}})`；kind 为 Rust Request 枚举定义的操作，不接受任意 shell、路径或 URL 执行。能力位表示对应代码已接入，不表示模型已加载或权限已授权。当前操作与 DTO 见 apps/desktop/src-tauri/src/commands.rs 和 apps/desktop/src/bridge.ts。下面表格为逻辑操作契约，尚未实现的高级能力见运行记录。

新增命令须同时修改 Rust handler、AppManifest 命令清单、Tauri capability、TS 类型和错误用例。前端只拿 DTO，不能返回 Keychain 内容、API Key、模型文件绝对路径或任意文件句柄。

## 2 时间、版本与范围

- JSON 一律 snake_case，ID 为应用生成的不透明字符串；不能使用模型生成的 ID 写主记录。
- 录音位置为安全整数毫秒，半开区间 `[start_ms,end_ms)`，要求 `0 <= start_ms < end_ms`。有效时长不包括主动暂停。
- 音频保留原始样本计数与单调时钟锚点。墙钟使用 RFC3339 UTC 字符串，会议时区使用 IANA 名称，不能用 UTC 墙钟计算音频间隔。
- transcript 快照保存具体 `segment_id + revision` 列表及 hash，不只保存最后段号。覆盖列表与快照关联；缺失/失败分别列出。
- 会议 `generation` 在撤销授权、删除或使在途结果失效时递增。配置版本、人工 revision 与授权版本均进入任务输入快照。
- 业务提交先事务落库，再发事件。事件 sequence 按会议递增，运行时重启以新快照恢复；不能靠事件流作为唯一事实来源。

## 3 命令契约

| 命令 | 请求 | 成功与约束 |
| --- | --- | --- |
| create_meeting | title、timezone、config | ID 与 ready 快照；默认 transcript_only |
| start_recording | meeting_id、sources | 全部成功才 recording；失败回滚；互斥检查 |
| pause/resume/stop_recording | meeting_id、expected_version | 更新 epochs，暂停/停止等待采集回调排空；停止后整理异步运行 |
| summarize_now | meeting_id、scope | job_id，输入截止已确认快照 |
| ask_meeting | meeting_id、question、scope | job_id；预览事件不代表可引用最终结果 |
| revise_transcript | segment_id、expected_revision、text | 新 revision 和 stale 关联项 |
| update_action | action_id、expected_version、changes | 新 version 或 VERSION_CONFLICT，不静默覆盖 |
| retry_job | job_id | 原键重试；输入变化需新任务 |
| cancel_job | job_id | 取消令牌与写回栅栏，取消不能撤回已经发送的数据 |
| set_analysis_consent | meeting_id、target、scope、automatic | 保存授权快照；撤销递增 generation |
| test_model_connection | model_config_id、version | 使用固定无会议内容文本，返回能力与错误 |
| export_meeting | meeting_id、artifact_version、format | 系统保存对话框选路径；只返回结果状态 |
| delete_meeting | meeting_id、expected_version | tombstone → 清理队列 → 删除完成；活动录制需先停止 |

当前服务使用会议 `version` 和转写/待办修订号进行并发保护，涉及普通状态的完整 CAS 扩展仍按验收推进；使用会议 `version` 进行普通状态 CAS，`generation` 专用于在途结果隔离；不能把领域枚举或单会议唯一索引当作完整并发控制。SQL 初始迁移仅是基础，服务接入时按迁移追加字段。

scope 仅允许 `all_confirmed`、`recent`（明确 duration_ms）、`selection`（明确片段和修订列表）。后端重新验证范围、会议归属、当前权限及上下文预算，不能信任前端传来的覆盖字段。

## 4 事件与错误

事件：`protocol_version, meeting_id, event_id, sequence, emitted_at, type, payload`。业务事件包括 recording_state_changed、transcript_committed、artifact_ready、actions_changed、job_failed；audio_level 与 transcript_partial 为可丢弃预览，不能持久化为事实。

统一命令错误 `{code,message,retryable}`。基本错误码已在 contracts 定义：NOT_IMPLEMENTED、INVALID_STATE、PERMISSION_DENIED、DISK_FULL、MODEL_UNAVAILABLE、VERSION_CONFLICT、CONSENT_REQUIRED、INVALID_EVIDENCE、INTERNAL。message 可读且不包含密钥、正文或原始请求头；更细错误按协议版本演进。

发现事件断号、重连或进程恢复时请求最新快照，不能默认重放旧请求。网络 retry 只重试可重试错误，自动上限为 2；JSON 修复最多 1 次，与传输重试分别计数。

## 5 数据库约束和仍需服务保证的事项

初始迁移包含会议、epochs、音频分段、覆盖、转写版本、配置、分析任务、产物证据、待办修订和清理队列。参会人身份、模板版本管理、聊天会话、笔记与全文索引将在对应阶段增加迁移。

数据库约束已覆盖：单活动会议、正向区间、状态枚举、任务键去重、跨会议与不存在修订引用拒绝。服务还须保证：current_revision 真实存在、修订不可变、禁止删除中的新写入、人工锁定字段、授权/版本原子写回、文件路径约束和日期解析。JSON 列的 json_valid 只检查语法，不等于业务 Schema 校验。

应用打开每个连接后启用 foreign_keys；运行库启用 WAL 与 synchronous=FULL 并验证文件 sync。迁移前做包含 WAL 的一致备份，失败回滚后继续使用原库。Python 内存库测试不能证明磁盘断电可靠性。

## 6 当前传输实现

运行版使用约 1.2 秒轮询完整会议快照恢复 UI；没有依赖瞬态事件保存业务事实。业务先落库，partial/电平为可丢弃的内存状态。上述统一事件信封是后续推送协议，当前不宣称已实现序列重放。分析适配器当前使用非流式 Chat Completions，后台显示任务状态；不支持的流式能力明确返回 false。错误当前为脱敏可读字符串，结构化错误码留作协议演进。

## 7 多配置与逐路采集扩展（已接入）

继续通过既有 dispatch 命令调用，外层 Tauri 命令清单仍为 get_system_status/dispatch；新增 Request 变体与前端 DTO 同应用构建交付，不开放任意命令。capability 描述已更新。

| kind | 请求与结果 |
| --- | --- |
| model_profiles | 返回 profiles 和 default_profile_id；每项为当前版本脱敏 DTO，不返回 credential_ref 或密钥 |
| save_model_profile | profile 含可选 profile_id/expected_version、名称、Base URL、model、context_tokens、max_output_tokens、timeout_seconds、key_action、api_key；返回新版本 DTO |
| set_default_model_profile | profile_id；只改变新会议初始选择 |
| test_model_profile | profile_id/config_version；固定文本，返回文本连通性、streaming=false、逐任务 JSON 校验说明及时间 |
| switch_meeting_model | meeting_id/expected_version/profile_id/config_version/enabled/interval_minutes；切换时明确选择是否授权分析 |
| archive_model_profile | profile_id/expected_version；归档并停止关联新请求，清理凭据、保留历史 |
| consent | meeting_id/expected_version/enabled/interval_minutes；对本场绑定配置授权/撤销，冲突不覆盖 |
| save_asr_settings | language；与文本模型配置分离 |
| retry_model_import | 重试旧单配置迁移；凭据失败不阻止录音 |
| set_microphone_enabled | meeting_id/expected_version/enabled；经持久化线程顺序处理，返回会议快照 |
| preview_audio | source_mask/input_device；主动采集三秒，返回各路 RMS 峰值，不保存音频、不转写 |
| record | 原有字段新增可选 confirm_microphone=false；关闭麦克风后继续时需明确恢复，否则拒绝带麦克风的恢复请求，可选择仅系统音频 |

ModelProfile DTO 包含配置 ID/版本、名称、服务/模型、本地分类、上下文/输出/超时、has_api_key、credential_valid、archived、latest_version、bound_meetings、last_test。未被撤销的凭据引用不保证 Keychain 当前可访问，真实读取失败显示错误，不自动采用其他配置。

会议快照新增 model_profile、sources、consent_version；sources 逐路包含 source/state/device/gap_start_ms/reason，state 为 active/disabled/failed/stopped。采集状态与分析 generation 独立。错误目前仍为脱敏字符串；完整结构化错误与推送事件为后续协议工作。

迁移、授权和取消规则见[增补方案](./多模型配置与线上会议录制方案.md)，实际证据见[增补开发验证](./增补功能开发验证.md)。
