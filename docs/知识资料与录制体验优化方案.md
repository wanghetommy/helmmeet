# 知识资料与录制体验优化方案

版本：V0.1 · 日期：2026年10月19日 · 范围：R39–R44 / A39–A44 / J01–J06

本文落实用户本轮五项需求。知识资料、默认分析和页面收敛属于待开发方案；本轮已着手修复可复现的混音与回听接缝问题，证据另记，不将方案等同于已交付功能。

## 1 产品决策

| 事项 | 决策 |
| --- | --- |
| 是否建知识库 | 建本机轻量资料库，先做“资料管理 + 经确认术语库 + 全文检索”，不引入独立向量服务 |
| 专有词放哪里 | 全局维护可复用词库/资料集合；每场选用集合并补充本场术语、参会人和背景。本场信息不自动污染全局 |
| 词形一致 | 本地 ASR 提示 + 经确认别名归一 + 人工纠错回馈；有歧义的人名保留待核对，不承诺只靠提示词实现零错误 |
| 分析入口 | 有有效模型即默认可用，主页面不再要求逐场点击“允许”。自动调用由“自动总结”开关控制，手动总结/纪要/发问由用户动作触发 |
| 页面 | 常驻状态压成一条紧凑工具栏；开始录制成功后进入专注布局，主要空间给会议记录和三个分析标签 |
| 音质 | 优先修正软件制造的幅度/播放接缝，保留原分轨。原始麦克风已有的物理爆音、削波或丢帧需分开定位，不能用强降噪掩盖 |

## 2 本机资料库：全局资产、本场选用

### 2.1 两层作用域

**全局资料库**用于保存长期可复用的团队/产品/项目资料、人员卡片和术语集合。术语卡至少有标准写法、类别、人名/产品/缩写等、明确别名、可选读音提示、适用集合、来源、确认状态和版本。可将用户明确确认的“王贺 → 王鹤”作为某个项目/人员范围的别名规则，而非自动成为所有会议的替换规则。

**本场资料与术语**引用若干全局集合的版本，叠加本场人员名单、临时产品名和本次资料。优先级为“用户本场确认 > 本场选用集合 > 已开启的通用词库”。同一级冲突不静默择一，显示待确认。本场开始时保存生效快照；会中新增或改词生成新版本，后续片段采用新版，已生成原文/产物不被静默重写。

现有“专有词与背景”拆为：

- **本场术语**：标准名、别名、类别，结构化编辑，可从选用词库继承。
- **会议背景**：目标、议程、项目背景，保留自由文本，默认只属于本场。
- **本场资料**：选用全局集合或为本场上传文件；显示本次生效的术语/资料版本。

原有 terms 自由文本升级时保留为“待整理的本场补充”，不直接转成已确认替换规则。人名不能仅凭近音就认定为同一个人：若参会名单里同时有王鹤和王贺，或者发言实际提到第三人，必须保留区别；知识词库也不等于声纹识别，不会据此给发言自动冠名。

### 2.2 导入与存储

首版导入 TXT、Markdown 和 CSV 术语表，提供内容/候选词预览，用户确认后进入生效词库。第二步增加有文本层的 PDF 和 DOCX；扫描 PDF/OCR 单独列后续项，不把空提取显示为成功。导入状态区分解析中、待确认、可用和失败，可重试、删除。

文件复制到受控本机目录，使用内部 ID、内容 hash 去重、来源文件名和解析器版本；解析不执行文件中的指令、脚本、外部链接或宏。解析设单文件大小、页数和时间上限，大文件提示拆分；任务在独立工作线程执行，不进入音频回调和音频写盘队列。

SQLite 保存文件/版本、资料块/页码、术语/别名、集合关系和本场绑定；正文原件在受控目录，索引可重建。FTS5 用于段落全文检索；人名和短词使用标准名/别名索引及转义后的字面匹配，不依赖三字切分索引找到“王鹤”这样的两字人名。先不需要独立数据库、向量服务或常驻嵌入模型；只有实际问答检索评估显示不足时，再评估本地语义索引。

### 2.3 对转写和问答的不同作用

```text
选用资料 → 提取候选词 → 用户确认 → 本场词库快照
                                    ↓
本地音频 → Whisper 受限术语提示 → 原始 ASR 修订
                                    ↓
                           明确别名归一 / 歧义待确认
                                    ↓
                          可核对的当前文本 → 分析

本场选用资料 → 检索相关段落 → 助手解释背景（资料引用）
会议原文修订 → 核对讨论事实 → 纪要/回答（会议引用）
```

资料中的观点不能伪装成会上说过的话；两类证据使用不同来源类型，界面标“会议原文”或“背景资料”，分别定位到原文修订或文件版本/页码/段落。纪要的已决、共识、负责人和期限仍必须有会议原文依据。

资料解析和 ASR 术语提示都在本地。默认分析可用不代表整份资料自动外发：文本模型只接收本场实际任务所需的术语、背景和检索片段，设置中可查看该范围。未选用集合、其他项目资料及全文档不自动加入；全部内容和凭据仍不写日志。

## 3 转写术语与前后一致

### 3.1 ASR 前提供有限上下文

当前 decode 每批创建状态，且未给 Whisper 配置 initial_prompt；现有 terms 实际只进入文本分析背景，不能当作已实现的 ASR 热词。本轮后续需接入本场生效术语，以及少量最近已确认句子的本地提示。通过固定版本 whisper-rs 的 `set_initial_prompt` 接口传入；按实际 tokenizer 控制预算，初始以不超过 128 token、且不超过模型允许提示窗口为上限，近期句子与词表共用预算。优先给参会人和当前议程词，不把整份资料堆入提示。

提示是识别辅助，不是硬词表，也不能保证听不清的人名被正确识别。保持静音/重复识别抑制和原音频覆盖，不因为词库里有某个词就补写未说过的话。

### 3.2 ASR 后做有来源的归一

- 只自动应用**用户确认、当前范围唯一且无已知冲突**的别名/错误写法规则；不做无条件全局同音替换。
- 词条冲突、否定/引用场景不清、同音真实人员并存时仅提示核对；无证据不补姓名。
- 保存原始 ASR 文本；归一生成独立可追溯修订，记录规则 ID、词库快照、原始修订和变更位置。用户可查看“王贺 → 王鹤”、撤销或改回。
- 追加数据库迁移扩展修订来源为 lexicon 等机器归一来源；现有 CHECK/外键需要有备份和事务的受控迁移，不能把机器改词记为人工编辑，不能原地改写旧迁移。
- 一次 ASR 确认及其首次归一在同一事务提交，避免 partial 和归一反复触发总结。会中修改旧文则新增 revision、使关联产物过期，沿用 generation/写回栅栏。
- 人工纠正可选择“仅此处”“本场同名表达”“加入某全局集合”。批量应用先预览有多少处，不能自动把所有相近名字改成一个人。

一致性目标是“已经确认属于同一实体的写法统一”，不是“把所有近音词都统一”。验收同时测正确归一与误改率，不能仅看文字表面一致。

## 4 页面与设备设置收敛

### 4.1 主界面移除常驻技术信息

移除独立占一行的“文本模型：已迁移的文本模型 v1”、麦克风检查峰值、静音/耳机/外放等长提示。版本、服务地址、技术诊断放到设置详情；主页面不再显示“已迁移”等内部名称。正常时只显示必要的录制状态/时间，发生设备失效、保存失败或模型失败时再显示可处理的异常信息。

不再有单独占高度的 source-strip。会议使用的模型从分析区的简短模型选择器或“⋯ → 模型设置”查看/切换，模型有效时不显示启用按钮。历史产物原生成模型和版本仍可在来源详情查阅。

### 4.2 三秒检查与麦克风设置合并

音源/麦克风选择旁统一提供“设备设置”按钮或弹层：音源模式、输入设备、测试 3 秒、测试中的动态电平及结果。弹层关闭后收起电平，主页面不常驻峰值；成功只给短暂“输入正常”结果，静音/无信号提示可重试。

设备测试只在用户点击时运行，不因打开设置或开始会议自动采集额外三秒。真实录制仍由“开始录制”触发；首次系统权限继续交给 macOS。设备失败属于异常，不因页面精简而隐藏。

## 5 模型分析默认可用

这是用户本轮对旧逐场授权流程的明确修订，后续实现应以本节为准，不能继续要求每场先点一次“本场分析设置 → 允许”。

| 条件 / 动作 | 预期行为 |
| --- | --- |
| 已配置有效默认模型，新建会议 | 自动绑定该明确版本，分析可用，不弹重复授权窗 |
| 自动总结关闭（新会议默认） | 不定时调用模型；仍可手动总结、生成纪要、发问 |
| 用户打开自动总结 | 直接按 60 字或 15 秒 / 1 / 3 分钟调度，不要求另开“允许本场分析” |
| 手动总结 / 纪要 / 发问 | 该操作直接提交相应任务，无第二次允许点击 |
| 未配置、模型归档、凭据失效 | 显示“配置模型”或具体失败，不阻塞录音，不偷偷回退服务 |
| 用户全局暂停 AI 分析 | 自动任务取消、手动入口明确暂停；自动总结开关不能绕过这个明确选择 |
| 旧会议用户曾明确关闭/撤销分析 | 保留该决定，不因升级自动恢复；通过清楚的恢复操作继续，不能当作普通新会议默认 |
| 换模型 | 保留会议绑定/版本栅栏，取消旧任务；普通本场切换一次确认即完成，不再叠加 summary_context/chat_context 的重复勾选 |

全局设置简洁说明默认服务和发送范围即可，不增加逐场审批流程。自动总结的开关管理**是否自动执行**；模型配置管理**用哪个模型**。后台保留目标/版本校验、取消及最小输入范围，不为了省点击删掉竞态保护。

升级需区分“旧程序新建时默认 transcript_only”与“用户明确关闭”。依据已保存的配置/撤销记录迁移；来源不明时不伪造用户曾授权，更不能覆盖明确关闭。旧 5/10 分钟策略不静默提频；新默认可用也不自动打开未开启的总结。

知识资料的本地导入不自动触发云分析。配置/触发分析时可查看实际范围，不在每个模型请求前重复打断。

## 6 录制后专注布局

顶部录制成功后压缩为一行或至多两行紧凑工具栏：会议名（可省略长名）、状态/时长、音源菜单、暂停/结束、更多。日期、背景、长模型名、测试电平和说明文字全部移入可展开详情。以开始录制**成功事件**进入专注态，不在用户刚点击但启动失败时隐藏错误。

```text
会议名 · 类型   ● 录制 12:30     音源 ▾  暂停  结束  ⋯
┌──────────────────────────┬─────────────────────────┐
│ 会议记录  实时 / 原稿       │ 总结 | 纪要 | 助手       │
│ 搜索 / 原稿来源 / 复制      │ 自动总结 / 当前操作      │
│                          │                         │
│     独立滚动的正文区域      │     独立滚动的分析区      │
│                          │                         │
└──────────────────────────┴─────────────────────────┘
回听：位置 / 播放暂停 / 音量
```

以剩余视口高度计算主工作区，目标在 1440×900 下两块主要正文区域可见高度不少于 600px；紧凑顶部约 56–72px、播放器约 48px，实际测量并记录。左右初始约 55:45，可调整到 35:65–65:35；侧栏可收起。名称“通用会议助手”作为类型/模板信息，不再单独制造一块高标题。

开始时仅做一次滚动/焦点定位到工作区，保留键盘焦点和未发送问题；后续转写更新、总结返回不强制抢滚动。暂停后仍保持专注布局，停止后不跳页；可手动展开会议信息或退出专注。切换查看其他会议不改变活动录制目标。

窄窗口沿用上下布局、记录可收起；活动采集的暂停/结束始终可达。各模块异步任务不能锁住录制控制。

## 7 咔哒声：分层定位与修复

用户已补充：断续爆音、导出 WAV 也有。因此优先核对原始分轨、时间轴和混音，不能只换播放器或直接称为环境底噪。

### 7.1 本轮发现与修复边界

1. 当前混音按每个采样“实际存在的音轨数”取平均。当一路暂缺数据时，另一条从 1/2 增益跳到 1，再回到 1/2；合成持续波形能复现人为幅度突变。本轮改成按会议选定/保存的音源数保持固定增益，作用于回听、ASR 混音和 WAV 混音导出；独立分轨保持原增益，缺失仍是缺失。
2. 原回听每 30 秒销毁并重建 HTMLAudioElement。改用同一 AudioContext 时间轴、PCM 预取与相邻缓冲精确接续；只有用户开始/暂停/拖动和最终结尾做短增益渐变，不在正常分段边界做多余淡入淡出。数据来不及则明确暂停，不偷偷塞入不连续播放。
3. 这些修复不改写原始分轨，也不能恢复采集前就削波/丢失的音频。最近一组本机录音的有限只读波形检查显示为麦克风单轨，无明显削波或时间轴洞，因此双轨增益缺陷**不能单独解释用户这段录音的全部咔哒声**。还需验证原生分包转换与硬件/输入处理；在用户真实问题回归前不宣称全部消除。

### 7.2 后续真实问题定位

比较同一时刻的：麦克风原始分轨 / 系统分轨 / 混音 WAV / 应用回听。统计而不记录会议内容：削波比例、连续性、掉帧/队列溢出、转换错误、噪声与有效语音电平。单轨也有时查输入设备、实际采样率与转换；仅混音有时查对齐/增益；仅回听有时查缓存/接缝。不要通过调小播放器音量来当成修复。

44.1/48kHz、单双声道和变化分包的原生转换用合成正弦波先测；用真实设备重现时只按用户明确授权开启采集。发现真实缺口保留 coverage 标记，不用虚假插值掩盖。确认需要环境降噪时，再提供可开关的本地人声增强，另存处理版；原版可切换、导出标记处理来源。语音处理/AEC 对设备兼容性和人声失真需实测后决定默认，不直接上强力降噪覆盖证据录音。

## 8 数据与接口草案

以下是待开发接口，不代表已注册可用。

- 全局：knowledge_documents / document_versions / knowledge_chunks + FTS5；term_sets / terms / term_aliases，含版本、作用域、确认来源。
- 本场：meeting_knowledge_bindings / lexicon_snapshots，引用生效版本而非动态读取全局最新；历史使用的版本保留。
- 原文：追加归一修订来源、derived_from、规则/快照关系及审计表；引用始终绑定 segment/revision。
- 全局默认：analysis_policy（默认就绪、全局暂停），会议保存模型绑定和明确停用来源；旧授权字段经迁移兼容，不再当作用户每场必须点击的前置条件。
- IPC：list/import/preview/confirm/delete knowledge、list/save term、bind_meeting_knowledge、preview/apply_normalization、set_analysis_policy。实际加入时同步 dispatch schema、权限描述、协议和测试；不开放任意路径、URL、shell 或云上传。

| J02 | 全局资料/术语库与本场版本绑定 | 追加迁移/解析任务 | 待开发；TXT/MD/CSV 导入、预览确认、删除隔离、短人名检索，TC-39 |

| J04 | 默认模型就绪与旧状态兼容 | 现有模型队列/迁移 | 待开发；无需逐场允许，自动开关直接生效，明确停用不被升级覆盖，TC-42 |

优先 J01 修复；随后 J04/J05 减少操作和占屏，再接 J02/J03。自动化检查不等同于真实设备/真实会议质量验收。既有 60 字或 15 秒、返回后开窗、独立纪要及录音优先级保持。

## 10 依据
