# 浏览器唤起与新建会议

2026年10月20日。R73 / A73。支持现有macOS Apple Silicon / Intel工程。通过自定义URL协议唤起应用并预填会议准备页；Windows/Linux的安装器注册不在本轮范围。

## 链接与参数

打开应用：`helmmeet://open`。

发起会议：`helmmeet://open?action=new-meeting`。

指定名称与类型：

```text
helmmeet://open?action=new-meeting&title=%E9%A1%B9%E7%9B%AE%E5%91%A8%E4%BC%9A&type=weekly
```

| 参数 | 规则 |
| --- | --- |
| action | 新建时必须是new-meeting；只打开应用时不带参数 |
| title | 可选，默认沿用准备页日期名称；去首尾空白，1–160个Unicode字符，不接受控制字符 |
| type | 可选，默认general；支持general、weekly、review、decision、retro、brainstorm |

会议类型分别对应通用会议、周会、方案评审、决策、复盘、头脑风暴。每个参数只能出现一次；未知参数、动作、路径、主机、片段、用户名/密码/端口、损坏的百分号编码和无效UTF-8均拒绝；链接最长4096字节。字段不会作为HTML或命令执行，不支持通过链接设置模型/密钥、选取本机文件、授权资料或自动录制。

网页从用户点击操作打开，例如：

```html
<a href="helmmeet://open?action=new-meeting&amp;type=weekly">用 HelmMeet 发起周会</a>
```

动态参数建议交给URLSearchParams编码，不手工拼接名称：

```javascript
const target = new URL('helmmeet://open');
target.searchParams.set('action', 'new-meeting');
target.searchParams.set('title', '项目周会');
target.searchParams.set('type', 'weekly');
// 在用户点击按钮的处理函数中执行。
window.location.href = target.href;
```

## 使用行为

- 冷启动：应用启动后进入预填的会议准备页，不等待网页持续连接；取消不会建立空会议。
- 已运行/窗口隐藏或最小化：唤回同一应用的主窗口，由系统发送URL事件。
- 正在录制、暂停、中断或收尾：只展示外部新建请求，不切换/结束现有录制；用户可忽略，会议结束后再处理。
- 已在准备页或其他工作区：显示“网页请求发起会议”，用户选择“打开会议准备”或“忽略”；不覆盖当前输入。确认打开时按原有返回保存流程保存已编辑准备信息，保存失败不消耗外部请求。
- 链接只预填名称/类型，不创建数据库会议、加载Whisper、开始录音或调用模型；开始录制仍由准备页按钮执行。
- 未编辑的链接准备页可以主动保存；直接取消/返回不自动创建空会议。短时间相同请求去重，最多保留八个待处理请求；请求仅存本进程内存。

## 工程与系统注册

`Info.plist/CFBundleURLTypes`注册helmmeet；使用现有Tauri的macOS `RunEvent::Opened`接收URL，无新增插件、包依赖或本机HTTP监听服务。后端严格解析后写入LaunchInbox，界面只接收结构化名称/类型。`launch-link`事件负责通知；新增受限IPC `launch_request`读取/按ID确认队首，解决冷启动事件先于React监听导致丢失的问题。对应app_manifest与main capability同步加入白名单。

新版构建后先正常打开一次完整HelmMeet.app，让系统识别协议；发布安装时建议放在稳定位置如Applications，再使用网页链接。浏览器可能要求确认打开外部应用。纯Vite网页预览或直接运行未注册的二进制不等同于已安装协议处理器；本轮不提供自动下载安装落地页。存在多个旧版本时，以系统当前关联的版本为准，需关闭旧版并打开新版。

技术参考：[Apple自定义URL协议](https://developer.apple.com/documentation/xcode/defining-a-custom-url-scheme-for-your-app)，具体Opened变体以项目锁定的Tauri 2.12.4 macOS源码为准（在线默认Linux构建文档可能不显示该变体）。

## 验收

TC-73覆盖：无参数只唤起；带new-meeting冷启动/热启动；名称URL编码及类型预填；取消不落盘；已编辑草稿不被替换；显式打开前保存旧草稿；录制中不能由链接结束或开始录音；重复请求不重复创建；非法链接不执行；新IPC限制在main窗口，主进程保留退出保护。工程与本次实测结果见[验证记录](./验证记录.md)。
