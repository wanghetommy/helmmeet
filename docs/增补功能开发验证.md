# 多模型与线上录制：开发验证记录

日期：2026年10月18日 · 范围：N01–N05 / R13–R22 / TC-21–26 · 本地开发版

## 1 已接入

- 多套文本模型配置：新增、编辑新版本、复制（默认无密钥）、连接测试、设默认、归档删除。支持同服务地址不同模型/账号，独立 Keychain 引用；读取 DTO 无密钥和 credential_ref。
- 会议固定配置版本；默认只影响新会议，编辑不改旧绑定。会前/会中/会后可切换，明确选择是否启用文字分析，不自动补发历史或回退其他模型。
- 切换、归档、凭据轮换和撤销只隔离关联任务。HTTP 等待及退避期间检查取消，在途 future 可释放，派发/重试/结构修复/归并/最终事务有栅栏；已经发送的文字不能撤回。
- 配置、任务与产物溯源。Markdown 显示原生成配置、模型及版本；旧结果及人工修订保留。
- SQLite v5/v6 追加迁移、升级一致备份、模型版本不可变、会议绑定复合外键、凭据跨存储 pending/cleanup 记录。旧单配置一次导入；Keychain 失败保留原信息和重试入口，不阻止创建录音会议。
- 线上双音源预设、全系统声音范围提示、麦克风设备选择及三秒不落盘电平检查。独立关闭麦克风会停止 I/O、移除 tap 并排空回调；系统轨可继续。暂停后继续需明确恢复麦克风，默认输入固定为本场实际设备，不静默改换输入。
- 音源故障按路报告并保留另一已选轨；双路失效、共享队列溢出、磁盘错误或睡眠中断整场。正常静音不会仅因电平低而被判设备故障。
- 同一主时钟对齐、16kHz 有界连续长度修正；真正缺帧仅记缺口，不在归档 WAV 内写入假静音。缺失仅在混音计算中填充，证据位置保持统一。

## 3 尚需真实设备验收

TC-21–24 的真实 Keychain 授权、真实服务组合和完整升级故障矩阵仍需核对。TC-25/26 的完整通过需要真实麦克风/系统声音授权、耳机双方交谈、麦克风关闭与恢复、权限撤销、设备断开、会议软件/浏览器、蓝牙路由、回听排除及两小时实际同步校准。

本轮没有采集现场声音，也没有调用真实远程模型。没有把模拟时间推进称为两小时实机稳定性通过。外放通用 AEC、按应用/浏览器标签页采集、多模型自动路由、流式 UI、完整 token 计数器仍未承诺；当前使用保守字节预算控制输入，服务实际上下文和输出质量需逐模型评估。

## 4 运行

正常运行 `npm run desktop:run`，或打开 `target/release/bundle/macos/HelmMeet.app`。首次升级导入原文本配置，已有会议需显式选择配置并重新确认分析范围。不要把远程模型选中状态等同于授权。

开发 UI 回归可用 `HELMMEET_DATA_ROOT` 指向隔离目录；要避免导入个人开发配置，应先在该目录准备无密钥的 settings.json。不得使用此变量绕过文件权限或把真实会议放入测试夹具。
