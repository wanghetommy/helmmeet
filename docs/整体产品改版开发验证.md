# 整体产品改版开发验证

2026年10月19日 · D01–D06 / R39–R43、R45–R49

## 本次实现

- **D01：**`meeting-core/product` 计算准备、会中、会后三个阶段。Detail 返回数据能力：已落盘音频、已确认文字、纪要、行动、模型与全局暂停。准备页没有结果、对话和播放器；后端分析、导出仍验证阶段与数据。
- **D02：**工具栏、活动会议横条、菜单栏“结束当前会议…”和 Cmd/Ctrl+Shift+E 共用确认流程。默认焦点为取消；Escape、遮罩和取消不调用停止。冻结会议 ID、版本和录制 epoch，后端校验后才停止、排空持久化线程；收据去重保证重试幂等。状态变化时要求重新确认。故障停止与进程退出保留原生命周期。
- **D03：**会议列表默认首页，支持名称、状态和类型筛选；全局资料、设置职责分开。发起进入准备表单，未编辑返回不建空会议，已编辑离开保存准备信息。名称、类型、音源在首屏；背景、资产和模型设置折叠。开始成功后才进入工作区。
- **D04：**共享浅色 tokens、品牌蓝 #0A3281，沿用已确认帆船。紧凑工具栏、会中默认收起导航、55:45 双栏，可拖动或键盘调整35–65%。记录/助手独立滚动；保留每场问题、笔记、搜索、版本和阅读位置。原稿当前/原始来源、全文复制、修订和证据仍可用。设备测试与麦克风/降噪/AEC设置归到同一弹窗，持续保留真实错误。普通成功用临时提示。
- **D05：**会后默认纪要，独立行动事项、助手；原文/录音按需展开。纪要手动生成、确认、人工副本、选定版本导出；续会建立新的准备会议及来源关联。全局 TXT/MD 资料、CSV/手工词库在本机预览保存，归档保留版本；每场显式绑定不可变版本。SQLite FTS5 trigram 按绑定版本检索，支持二字补充匹配、重建索引。Whisper initial_prompt 仅取标准词和临时术语；每个识别片段保存提示版本。明确别名采用原文统一预览、选中应用和可撤销修订；冲突跳过，人工修订不批量覆盖。原始 ASR 保留，旧分析过期。
- **分析默认：**有可用默认模型的新会议立即就绪，自动总结默认关闭；旧会议和显式停用不自动开启。自动总结继续采用60字或15秒、1分钟、3分钟的串行调度；全局暂停取消在途/排队任务并阻止新任务。选用资料只进入必要背景片段，不作为会上事实证据；产物保存背景版本与来源。

SQLite v10 为追加迁移；升级前备份。没有改写已发布迁移、用户音频或模型凭据。

## UI 验证复现

先 `npm run build`，再 `python3 tests/integration/check_workspace_ui.py --port 1421`，使用浏览器打开打印的本地地址。该服务只给正式构建注入清楚命名的合成 IPC 数据；没有浏览器驱动、系统剪贴板、音源或模型访问。页面操作仅改变内存夹具，刷新恢复。浏览器普通预览与真正桌面应用均不包含该夹具。

检查路径：列表搜索/筛选 → 新建后直接返回无空会议 → 编辑后返回保留准备信息 → 设备设置 → 选用资料版本 → 开始后的专注工作区 → 原稿来源/全文复制 → 总结/纪要版本互不干扰 → 按类型提问/草稿保留 → 查看B时取消/确认结束A → 会后纪要/行动/证据/续会 → 全局资料维护/模型/音频/数据设置。检查1440×900、800×900、320×720及键盘取消/焦点/标签切换。
