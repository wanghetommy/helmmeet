# 本地运行版：能力与验证

日期：2026年10月18日。构建：macOS arm64，HelmMeet 0.1.0。原版检查未采集现场麦克风，远程测试只用固定文本和合成语音。多模型与线上录制的最新结果见[增补开发验证](./增补功能开发验证.md)。

## 1 交付物

- 应用：`target/release/bundle/macos/HelmMeet.app`，不含模型；最终增补构建见开发验证记录。
- 启动：`npm run desktop:run`；从源码启动：`npm run desktop:dev`。
- 已完成本机 ad-hoc 签名和资源验证；没有 Developer ID、Team ID 或 Apple 公证，不是外部分发版。
- 已实际启动桌面应用，检查首次页面和设置页面，确认现有 GGML 文件、DeepSeek 地址/模型以及已配置密钥状态可见，真实 Key 不展示。

## 3 原版实测与工具（增补结果见独立记录）

- 隔离 Rust：1.99.1，CMake：4.4.4，Swift：6.3.3；JS 与 Rust 已分别生成 lock 文件。
- Metal 日志识别 GPU 为 Apple M5 Pro；正式机型、完整内存与性能档位仍需按验收模板登记。
- 本机 GGML 文件：1,624,555,275 字节，指纹与先前登记一致，模型不进入安装包。
- 自动化：17 项 Rust 测试（7 项领域 + 10 项后端）、3 项 TS IPC、7 项 Python SQL 测试通过；严格类型、Rust fmt/clippy、Vite 构建通过。
- 自行合成的英文语音约 6.896 秒，真实 ASR 返回 3 段；一次推理及测试持久化路径记录 555ms。该值不是首段延迟、中文 CER、重复窗口管线 RTF 或 P95 的统计结果。
- 真实 DeepSeek 测试生成 1 条行动候选和结构化纪要，后端证据校验、SQLite 提交、Markdown 生成、PCM 回听成功。没有发送用户真实会议内容。
- 初次沙箱语音合成只生成空文件，检查后重新生成非空合成样本再测试；不把首次空样本测试记为成功。
- 初次 Python 测试遇到当前环境自签根证书链问题，应用改为 macOS 系统 TLS 信任链后，真实请求通过；没有关闭证书校验。
- 上游 debug 推理日志可能包含 token 文本，运行版在启动时安装无日志后端的 whisper/ggml hooks，后续冒烟输出只有数量和耗时。

## 4 当前限制与验收待办

1. 真实麦克风/屏幕音频授权必须由用户在系统界面完成；本次没有自动授予权限或采集现场音频。
2. 两小时持续录制、双轨同步漂移、外放回声、实际设备断开/睡眠/磁盘不足故障注入、强制断电均待验收。不能声称全部 A01–A26 通过。
3. 分段重叠采用有限左上下文与时间过滤，复杂跨边界重复仍需中文语料调优；当前静音门控是能量阈值，未接入额外声学 VAD 模型。
4. 模型连接当前非流式；长文按配置的保守字节预算分批、二路归并。完整 token 计数、服务上下文超限的自适应重分批和语义召回质量仍需增强与真实模型评估。在途 HTTP 取消和退避检查已在本机假服务验证。
5. 相对日期保留原始说法，不自动写入未验证的标准日期；说话人身份未知，不根据声音认人。待办去重以已有事项文本/证据为主，复杂同义事项仍由用户核对。
6. Markdown 导出所选纪要与该版本引用的历史原文；TXT/CSV 导出当前转写和当前待办。混音与独立音轨 WAV 已提供，原生保存对话框和跨版本的完整导出矩阵仍需现场核对。
7. 无云同步、外部自动发消息、任务系统写入或应用层全量加密。Keychain 保存应用密钥；开发配置文件例外由用户明确授权。
8. UI 当前使用周期快照轮询；推送事件序号、结构化错误码和精细优先队列留作后续工程增强。
9. 多配置、会议版本绑定、独立凭据与切换隔离、独立麦克风关闭/恢复、单路故障继续和时钟修正已接入。自动化与隔离 GUI 验证见[增补开发验证](./增补功能开发验证.md)；真实 Keychain 权限、真实会议与路由、两小时实机同步仍待验收。

完整用例见[测试验收文档](./测试验收文档.md)。上述限制是实际交付边界，后续应优先补齐真实采集验收、长会议覆盖及边界质量，再扩大平台范围。
