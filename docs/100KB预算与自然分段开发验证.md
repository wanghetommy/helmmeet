# 100KB预算与自然分段：开发验证

2026年10月20日，R71/R72首版。按用户确认采用1.5秒软候选、3秒明显停顿，100KiB整请求上限。未录制或播放真实音频、未调用真实模型、未修改正式会议库/模型配置。两小时实机稳定性仍暂缓。

## 当前实现

- meeting-core/budget将100KiB字节限制与可用token数分别计算。通用文本结构估算（ASCII/中文/其他字符分别计量）加原有安全余量，usage只保存模型配置hash与最大观测比例，不存文字。未内置/冒称精确模型tokenizer，不额外增加模型包体。
- HTTP请求最终JSON（含工具结果二次转义）上限102,400字节，token预检独立；80KiB后不再扩大取证，原文/工具按剩余容量分页。小舵遇明确容量错误最多一次更小取证重试，保留原问题/冻结范围/历史；草稿提议幂等，不自动接受操作。结构化总结仍沿用有界批次和证据约束。
- meeting-core/paragraph聚合跨识别窗口的已确认片段：短停顿继续，1.5–3秒需句末且60字或15秒才封段，3秒明显停顿封段。45秒/250字句末择机，60秒/400字在已确认片段边界续段；暂停/epoch/缺失/未来明确说话人变化为边界。时间长度可能多一个原ASR片段，不强制改写未确认文字。
- activity复用现有Silero，从writer持久化后的流派生活动，独立于唤醒及自动总结。所有有效所选音源都新鲜且安静才确认停顿，失效/缺帧unknown不当静音，最多4次/秒更新同一静音区间；不阻塞录音采样回调。
- 追加迁移13保存活动epoch/停顿及模型token聚合量，epoch/meeting复合外键隔离、源会议删除级联。VAD主机时间按采集origin/base映射到录音时间。发言段由原文/停顿/epoch确定性重建，ID取首片段，成员带原修订；不另写一份原文副本。
- VAD停顿须等ASR连续处理水位追平后才能用于封段；新录制无VAD不靠“文字未返回”猜静音。旧会议无活动历史时只按片段间隙/长度分组，明确historical_gaps；新录制unknown长度兜底。暂停恢复、重启不会改掉原segment/revision。
- UI实时、原稿、复制按发言段组织，当前段持续增长，原片段在“核对与修订原文”展开；整段提问映射全部原成员，单片选区仍兼容。工具行含paragraph_id供助手组织连续发言，事实来源仍是原证据，不猜测说话人。

## 验证与证据

新增合成/本机假HTTP回归覆盖：100KiB整请求边界、独立token更紧窗口、usage聚合校准、上下文容量400一次减小取证、84片超过旧25KiB请求仍成功；短停顿/3秒/候选/长段/明确换人、双源新鲜度和unknown、ASR追平后边界/重启/原文引用及复制、整段选区、v13跨会议epoch外键/级联。

合成UI已核对：两条原片合成一个发言段，仍能展开逐片修订；整段提问范围为“选中段落”，对话原稿也合并显示；前端warn/error为0。截图仅含合成内容：artifacts/design/duozhou/speech-paragraphs.png。
