# ADR-0001：桌面优先与领域边界

状态：采纳为工程方向，原生集成和性能待验证。日期：2026年10月18日。

选择 Tauri 2 + React/TS、Rust 核心、Swift 音频适配与 whisper.cpp C API。先支持 macOS 14+ arm64 单用户，不建设账号服务、云同步或技能运行时。

原因：会议工作区适合 Web UI，Rust 管理本地任务与数据；原生采集必须遵守 macOS 权限与时钟。四端长期目标使协议和领域与采集分离有价值。SwiftUI 可简化 Mac 集成但需另建其他平台 UI；Electron 仍需原生适配，不消除主要风险。

代价：维护 Rust/Swift/C++ 构建和生命周期，需真实 Mac 长时间测试；Tauri 跨端能力不代表采集可以共用。若原生集成成本或实际团队能力改变，可保留协议与数据迁移重新评估 UI 框架。

骨架只开放能力查询，不提前授予文件、shell、HTTP 等广泛权限。SQLite 是结构化事实来源，音频文件是可恢复持久化来源；模型输出经应用校验才能成为候选产物。
