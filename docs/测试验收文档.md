# 测试与验收文档

版本：V0.2 · 日期：2026年10月18日 · 范围：macOS arm64 P0（含多模型与线上双源补充）

## 1 验收规则

状态统一使用“通过 / 未通过 / 待验证 / 不适用”，记录步骤、环境、实际值和证据。未接入、没运行、缺少工具均为待验证，不能标通过。自动化通过不替代系统权限、真实音频和模型语义质量验收。

最终 P0 要求 A01–A26 执行完成，无导致丢音、错误外发、数据损坏、人工结果覆盖或无法完成核心流程的阻塞问题。达不到性能目标的设备只能登记为不支持该实时档位，不能静默降低目标。

## 2 环境和样本

登记：Mac 型号/芯片/内存、macOS、Xcode/Swift/Rust/Node、Git commit、应用签名与启动方式、whisper.cpp commit、Metal 参数、模型路径别名和 SHA-256、LLM 服务/模型/模板版本、音源、耳机与采样率。凭据和完整真实会议不得放进测试报告。

样本：至少 30 分钟经授权的清晰中文人工转录，另设中英混合、噪声、静音、专有词、连续长句、重叠讲话；不少于 30 条明确待办，含多人同姓、改口、取消、跨午夜、相对日期和泛泛建议等反例。样本与标注保存在仓库外，记录许可、hash、标注规范和版本。不得用同一小样本调参后直接报告泛化质量。

双轨对齐样本：在开始和两小时结束附近分别向两输入通路注入可定位脉冲或短音，记录延迟；建议对齐误差目标绝对值不超过 100ms，最终按登记硬件和可重复方法固化。录音缺段与 ASR 漏字分别报告。

## 3 指标口径

| 指标 | 方法与门槛 |
| --- | --- |
| 首段文字 | 模型预热后首段语音开始到首次可读 partial；目标 ≤5s；预热耗时另报 |
| 确认延迟 | 每段末音频样本的单调时间到 final 提交；采至少 100 段，报 P50/P95/max；P95 ≤15s，常态目标 ≤10s |
| 有效 RTF | 实际管线总推理时间 / 新增音频时间，包含重叠重算；<1，建议 ≤0.7；本地 LLM 并发另测 |
| CER | 中文简体基准、去空白与标点，英文小写；字符编辑距离/参考字符数，清晰中文目标 ≤15%；英文 WER 另报 |
| 待办 precision/recall | 正确动作及证据一对一匹配，precision≥90%、recall≥80%；负责人、日期字段正确率另报，不把 null 算正确人名 |
| 事实与证据 | 抽查至少 30 项决定/风险/待办；每项引用存在且语义支持，不补造人名/日期/共识；关键事实无依据为失败 |
| 持久化窗口 | 正常写入每 ≤5s sync；强退重复至少 5 次登记最后可恢复样本；断电单独记录，不由强退测试推断 |
| 覆盖完整 | 对期望区间做集合差；静音已处理可覆盖，缺失录音、失败转写与未分析区间不可算完整 |

性能报告需包含原始匿名指标和计算脚本版本，不从平均值推算 P95，不把模型置信度换成识别准确率。

## 4 端到端与故障用例

| 用例 / 需求 | 操作 | 通过条件 |
| --- | --- | --- |
| TC-01 / A01 | 本机打包应用两小时持续录音，切前后台并回听 | 已保存两小时；无未提示缺段；无持续内存增长或卡死 |
| TC-02 / A02 | 耳机线上会议，本人与远端交替发言；首尾测同步 | 两轨独立可听、混音可听、电平独立；同步误差记录且达到登记门槛 |
| TC-03 / A03 | 开始、暂停 60s、恢复、再停止 | 暂停无采集，epochs 正确，证据时间与有效音频一致 |
| TC-04 / A04 | 预热后持续发言采 ≥100 段，再让本地 LLM 同机运行 | 首段/确认延迟/RTF/内存实测，达标或明确降级档位 |
| TC-05 / A05 | 对人工标注语料离线和实时识别 | CER/WER 有可复现记录，中文达标；噪声和混合另报 |
| TC-06 / A06 | 长句跨窗口、反复短停顿、静音 5 分钟、重叠讲话 | 无明显拼接重复/漏句；静音无持续幻觉；覆盖记录与文字分开 |
| TC-07 / A07 | 模型预装后断网，录音、转写、查找、回听、导出 | 基础全流程可用；缺失网络只影响远程分析，不触发云端 ASR |
| TC-08 / A08 | 抽查 ≥30 项事实，点原文与回听，含反对与未定方案 | 引用归属/修订/语义正确，建议不变成决定；不足时明确未提及 |
| TC-09 / A09 | ≥30 条标注待办及建议反例；连续两轮重复分析 | 达到 precision/recall；无重复；负责人日期可追溯，歧义待确认 |
| TC-10 / A10 | 改待办、转写、纪要，重新生成并模拟并发修改 | 原文/人工版本保留；模型只建议变更，冲突可见 |
| TC-11 / A11 | 活动 WAV 写入/封口/索引各时点 kill -9，重启五次 | 修复尾文件，孤儿补账，sealed 不重复；未完成任务可重试；期间缺失明确 |
| TC-12 / A12 | 假服务注入断网、429/Retry-After、401、5xx、超时、坏 JSON、上下文溢出 | 重试有上限；认证不自动重试；录音不受影响；无重复业务记录 |
| TC-13 / A13 | 拒绝/撤销权限、拔设备、睡眠恢复、低空间和写失败 | 正确停录或标中断；已有数据保留；不静默换麦；缺失原因可查 |
| TC-14 / A14 | 检查离线、本地与远程三模式网络；回环重定向公网、代理、恶意 URL | 无音频外发；授权前不发文字；本地模式不跟随重定向/代理到外部；日志无密钥 |
| TC-15 / A15 | 导出指定旧/新版本；注入引号换行、=+-@、前导制表符和 ../ 路径 | 文本/证据与选定快照一致；CSV 公式防护；路径限域；WAV 时间一致 |
| TC-16 / A16,R01,R02 | 开第二场录音，双源第二项启动失败，重复点开始 | 单活动会话；部分启动回滚，用户明确选择单源后才录制 |
| TC-17 / A17,R05,R07 | 流式生成中改文/换模板/撤销授权/删会，假服务延迟返回 | 无旧任务覆盖，无撤销后新请求；stale 标记与取消边界可见 |
| TC-18 / A18,R08,R10 | 删除时文件锁定后重启；搜单字/两字；问“全部决定” | 清理可重试、无残留写回；短词回退可用；穷尽问题扫描全量并显示漏块 |
| TC-19 / A19 | 模型不存在/损坏/下载中断/hash 错；旧数据库含 WAL 升级失败 | 不加载未校验文件；原子替换；迁移回滚不丢旧库，可恢复一致备份 |
| TC-20 / A20 | 窄窗、深浅色、键盘、系统字号、关窗/退出录制 | 无关键遮挡；状态不只用颜色；键盘可达；关窗继续状态可见，退出可取消 |
| TC-21 / A21,R13 | 保存本地/远程及同 URL 不同 Key 的两个配置，复制、改 URL、测试、清空 Key | 列表与测试对应各版本；假服务收到正确独立凭据；复制不带 Key、改地址不沿用旧 Key；前端/日志/数据库/导出无 Key |
| TC-22 / A22,R14 | 两会议选不同配置，改默认、编辑其中一项后重启，再显式采用新版本 | 新会议采用新默认但分析仍关闭；旧会议绑定不变；编辑提示新版本；显式采用才改变绑定，保留历史产物来源 |
| TC-23 / A23,R15 | 双源录制与 ASR 中切本地/远程/另一账号；假服务延迟返回；同时修改会议 | 录音/ASR 连续；旧队列不派发、迟到结果不写回；CAS 冲突可见；切换不补发全文，远程范围需确认，无关会议授权不受影响 |
| TC-24 / A24,R16,R17 | 升级旧单配置与有 WAL 数据库；注入 Keychain 写失败/迁移中崩溃；归档配置、轮换/撤销 Key，模拟旧任务重试 | 可恢复且不丢原数据、不泄密；未知来源明确标记；不扩大旧授权；失效配置/旧凭据不再派发，关联结果隔离，其他会议不受影响，无自动回退 |
| TC-25 / A25,R18,R19,R22 | 戴耳机线上双方交替发言；只开单路对照；分别用会议软件静音与助手麦克风关闭/恢复、暂停再继续；拒绝权限；回听本应用；播放其他应用声音 | 双轨与混音含正确内容；独立控制仅停麦克风、系统轨继续，暂停后不自动重开麦克风；会议软件静音行为说明清楚；显示全局范围，其他应用声音符合所示范围；本应用回放不进入系统轨，无视频文件，权限失败不伪装成功 |
| TC-26 / A26,R20,R21 | 双源两小时；起点/每 20 分钟/终点注入可定位校准信号；拔麦/撤单路权限/睡眠；蓝牙及输出路由变更；正常静音对照 | 目标对齐误差绝对值 ≤100ms，记录实际值及校准路径延迟；无累积漂移/未提示缺口；单路故障保留另一已选路且显示部分录制；双路失效中断；不静默换设备；静音不误报故障 |

R03/R04/R06/R09/R11/R12 在 TC-03/04/06/11/13/14/17 中额外检查，特别是跨午夜“明天”的日期及睡眠缺口。

新增 TC-21–24 自动化部分及 TC-25/26 假音源/合成时钟部分已通过，隔离界面流程已检查；真实 Keychain 权限和设备矩阵仍待验收，整项状态见[增补开发验证](./增补功能开发验证.md)。TC-25/26 至少登记一种原生会议软件和一种浏览器会议，分别记录内置/USB 输入、耳机与蓝牙设备的可用组合；外放作为回声质量观察，不据此宣称已实现 AEC。两轨校准使用有已知通路延迟的合成信号/测试设备，不用随意拍手估算时钟漂移。保留匿名测量数据和应用构建身份，不把双源入口能启动视为验收通过。

## 5 自动化层次

- 当前已有：TS IPC 输入边界；Rust 状态机/覆盖洞/引用快照；SQLite 单活动会议、跨会议引用、幂等键、修订保留与级联约束；文档链接检查。
- M1/M2 增加：PCM/WAV round-trip、WAV 截断修复、双轨偏移与漂移、取消生命周期、跨窗口去重和静音覆盖；离线 PCM 合成夹具不需现场录制。
- M3/M4 增加：本地假 HTTP 服务、SSE 分包/断流/取消、JSON Schema、上下文分批、写回 generation、CSV 安全、短词检索和迁移备份。
- M5 真实设备验收：按上表执行，记录在 tests/acceptance 中。CI 不请求麦克风、不外发会议，不依赖个人模型路径和凭据。
