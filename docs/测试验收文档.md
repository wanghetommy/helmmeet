# 测试与验收文档

版本：V0.4 · 日期：2026年10月18日 · 范围：macOS arm64 P0 与类型/对话/工作区扩展验收设计

## 1 验收规则

状态统一使用“通过 / 未通过 / 待验证 / 不适用”，记录步骤、环境、实际值和证据。未接入、没运行、缺少工具均为待验证，不能标通过。自动化通过不替代系统权限、真实音频和模型语义质量验收。

最终 P0 要求 A01–A26 执行完成，无导致丢音、错误外发、数据损坏、人工结果覆盖或无法完成核心流程的阻塞问题。达不到性能目标的设备只能登记为不支持该实时档位，不能静默降低目标。

## 2 环境和样本

登记：Mac 型号/芯片/内存、macOS、Xcode/Swift/Rust/Node、Git commit、应用签名与启动方式、whisper.cpp commit、Metal 参数、模型路径别名和 SHA-256、LLM 服务/模型/模板版本、音源、耳机与采样率。凭据和完整真实会议不得放进测试报告。

样本：至少 30 分钟经授权的清晰中文人工转录，另设中英混合、噪声、静音、专有词、连续长句、重叠讲话；不少于 30 条明确待办，含多人同姓、改口、取消、跨午夜、相对日期和泛泛建议等反例。样本与标注保存在仓库外，记录许可、hash、标注规范和版本。不得用同一小样本调参后直接报告泛化质量。

双轨对齐样本：在开始和两小时结束附近分别向两输入通路注入可定位脉冲或短音，记录延迟；建议对齐误差目标绝对值不超过 100ms，最终按登记硬件和可重复方法固化。录音缺段与 ASR 漏字分别报告。

## 3 指标口径

| 指标 | 方法与门槛 |
| --- | --- |
| 首段文字 | 模型预热后首段语音开始到首次可读 partial；目标 ≤5s；预热耗时另报 |
| 确认延迟 | 每段末音频样本的单调时间到 final 提交；采至少 100 段，报 P50/P95/max；P95 ≤15s，常态目标 ≤10s |
| 有效 RTF | 实际管线总推理时间 / 新增音频时间，包含重叠重算；<1，建议 ≤0.7；本地 LLM 并发另测 |
| CER | 中文简体基准、去空白与标点，英文小写；字符编辑距离/参考字符数，清晰中文目标 ≤15%；英文 WER 另报 |
| 待办 precision/recall | 正确动作及证据一对一匹配，precision≥90%、recall≥80%；负责人、日期字段正确率另报，不把 null 算正确人名 |
| 事实与证据 | 抽查至少 30 项决定/风险/待办；每项引用存在且语义支持，不补造人名/日期/共识；关键事实无依据为失败 |
| 持久化窗口 | 正常写入每 ≤5s sync；强退重复至少 5 次登记最后可恢复样本；断电单独记录，不由强退测试推断 |
| 覆盖完整 | 对期望区间做集合差；静音已处理可覆盖，缺失录音、失败转写与未分析区间不可算完整 |

性能报告需包含原始匿名指标和计算脚本版本，不从平均值推算 P95，不把模型置信度换成识别准确率。

## 5 自动化层次

TC-01/25 的麦克风启动回归需加入“输出 44.1kHz、输入 48kHz”的真实设备组合，分别测试系统默认输入与显式选择、首次授权后启动、正常重试和关闭/恢复。tap 必须与选定输入硬件格式一致；无实际状态变化的启动通知不应中断，真正的设备断开/格式变更仍需报告并按源处理。三秒电平预览只能证明短时启动，录音落盘与长时稳定性仍单独验收。当前修复证据见[麦克风故障记录](./麦克风启动故障修复.md)。

TC-11/13/20 增加退出矩阵：模型未加载/加载中/缓存空闲/推理中，分别走菜单退出、Cmd-Q、Dock/系统 Quit 及重复请求；采集中应拒绝退出，已结束采集则等待模型正常释放。排队中的采集/预览/分析不能在退出决定后启动；取消推理不标记已转写覆盖，重启可从原音频续转。使用 `check_metal_exit.py` 验证真实 Metal 与 AppKit 退出，不能仅用 CPU 或禁用 residency 通过。证据和未执行项见[Metal 退出修复](./Metal退出崩溃修复.md)。

- 当前已有：TS IPC 输入边界；Rust 状态机/覆盖洞/引用快照；SQLite 单活动会议、跨会议引用、幂等键、修订保留与级联约束；文档链接检查。
- M1/M2 增加：PCM/WAV round-trip、WAV 截断修复、双轨偏移与漂移、取消生命周期、跨窗口去重和静音覆盖；离线 PCM 合成夹具不需现场录制。
- M3/M4 增加：本地假 HTTP 服务、SSE 分包/断流/取消、JSON Schema、上下文分批、写回 generation、CSV 安全、短词检索和迁移备份。
- M5 真实设备验收：按上表执行，记录在 tests/acceptance 中。CI 不请求麦克风、不外发会议，不依赖个人模型路径和凭据。
