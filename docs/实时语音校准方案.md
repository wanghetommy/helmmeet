# 实时语音校准方案

## 目标

在不替换原始 ASR 文本、不阻塞录音和转写的前提下，使用已配置的文本模型修正错别字、标点和词典中的专有名词。模型输出属于可追溯校准版本，原始识别文本永久保留。

## 触发策略

校准只处理已确认的 ASR 段落，不处理 partial 文本。按模式累计完整发言段后调用：

| 模式 | 最少文字 | 最少段落 | 最长等待 |
| --- | ---: | ---: | ---: |
| 较快 | 400 字 | 2 段 | 45 秒 |
| 标准 | 800 字 | 2 段 | 90 秒 |
| 稳健 | 1200 字 | 3 段 | 120 秒 |

单次最多处理 4 段。上一段只读作为连续语境，当前批次才是修改目标。上一个校准任务未结束时不重复提交；会议结束时强制处理剩余段落。

## 上下文与词典

请求包含当前批次原始文本、上一段已校准文本、段落来源清单和本场绑定词典中命中的候选词。词典较大时只发送相关词条，不把整库重复塞入请求。词典中的标准词是唯一允许替换的专有名词来源；无法确认时保留原文并标记待确认。

## 校准规则

模型必须不增删事实、不改变原意、不补写未听到的内容。数字、日期、金额、单位、网址、代码和人名没有明确依据时不得修改。可以根据语义关系和已确认停顿适当增加、减少或替换中文标点，使段落更易读；不确定时少改，不能用标点改变陈述/疑问/否定语气或制造新的事实。

模型返回每个段落的 `corrected_text` 和 `changes`。宿主校验来源清单、数字序列、修改幅度和词典约束；数字变化、过大改写或未知专有名词进入 `needs_review`，失败只保留原始文本。

## 数据与 UI

`transcript_calibrations` 按会议、段落和来源清单保存 pending/succeeded/needs_review/failed 状态、修正版、修改项、模型版本和词典版本。原始 ASR revision 不被覆盖，当前会议正文可以显示校准投影并保留原片段核对入口。

会议纪要面板提供“实时语音校准”复选框和较快/标准/稳健频率选择。状态显示排队、已校准和待确认数量；关闭后不再发起新任务，历史校准结果保留。校准服务异常不改变录音、ASR、问答或会议纪要队列。

## 交付边界

首版只生成可追溯校准投影，不自动把高风险修正写入人工 revision。后续可增加低风险标点/词典替换的批量确认，并让已确认校准参与会议纪要和问答；仍需保留原始 ASR 引用。
